Peg Solitaire Game Engine
A C++ implementation of the classic Peg Solitaire board game engine. The project supports both English (33 holes) and Diamond (41 holes) board configurations, with comprehensive game rule enforcement and state management.
Key Features:



Support for multiple board layouts (English and Diamond variants)
Valid move validation and execution
Dynamic board state management
Deep copy functionality
Memory-safe implementation



Technical Highlights:
Custom 2D array implementation for board representation
Dynamic memory management
Copy construction with deep copying
Comprehensive error handling
Extensive unit testing coverage
